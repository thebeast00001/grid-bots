# Grid Milestone 1 ("First bot") Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A stranger runs one command, connects a model (ChatGPT plan, an API key, or a local model), makes a bot with a face in the Studio, gets interviewed by it, and is chatting with it, with memory, in under two minutes, on desktop or phone.

**Architecture:** One Next.js 16 app (`apps/web`) holds the UI, the API routes and the agent loop; no separate runner yet (nothing runs in the background in M1). Data lives in an embedded PGlite (Postgres-in-WASM) database plus readable Markdown mirrors under `GRID_HOME` (default `~/.grid`). Models go through Vercel AI SDK 7; the ChatGPT plan is an OpenAI Responses provider with a request-rewriting `fetch`. A small `gridbots` CLI package ships the standalone build so `npx gridbots` works without Docker.

**Tech Stack:** pnpm 10 workspace · Node ≥ 22 · Next.js 16.4.x · React 19.3 · Tailwind 4.3 · Motion 14 · Vercel AI SDK `ai` 7.x + `@ai-sdk/react` 4.x + provider packages · Streamdown 2.8 · PGlite 0.5 + Drizzle ORM 0.45 · Zod 4 · Vitest 5 · Playwright 1.65.

**Spec:** [PLAN.md](../../../PLAN.md) (§4 concepts, §6 stack, §8 models, §10 safety, §12 local mode, §13 M1 row) · [docs/UI.md](../../UI.md) (design language, motion tokens, critter system, UI features 1–40, 48–49) · [docs/FEATURES.md](../../FEATURES.md) (rows marked M1) · [docs/RESEARCH.md](../../RESEARCH.md) §4 (subscription rules). Throwaway reference implementation of the UI: `prototype/` (not part of the build).

## Global Constraints

- Node ≥ 22 (AI SDK 7 is ESM-only and requires it). Package manager pnpm 10.
- `next` ≥ 16.4.5 (Nov 2026 security release). Pin exact minors in `package.json` to the versions installed in Task 1.
- The server binds **127.0.0.1** only. Default port **3210**. Data dir `GRID_HOME` env, default `~/.grid`.
- Every mutating API request must carry header `x-grid: 1` and pass the Host/Origin guard (Task 3).
- Secrets (API keys, OAuth tokens) are sealed with the vault before storage and never returned to the browser; API responses expose only `hint` (last 4 characters).
- Every model call uses `streamText` (the ChatGPT plan rejects non-streaming calls), including internal calls: use `await result.text` where a plain string is needed.
- AI SDK 7 names: use `instructions` (not `system`), `isStepCount` (not `stepCountIs`), `onEnd` (not `onFinish`) on streams, `createUIMessageStreamResponse` + `toUIMessageStream` (not `toUIMessageStreamResponse`). Never put `role: "system"` messages inside `messages`.
- Never send `temperature`, `top_p` or `top_k` to any provider (rejected by the current Claude API and by the ChatGPT plan).
- Claude is offered by API key only. The providers page carries this line verbatim: "Claude subscriptions can't be used in third-party apps. Use an API key instead."
- ChatGPT copy, verbatim: button "Continue with ChatGPT"; composer badge "Using ChatGPT plan" with link "Manage usage" → `https://chatgpt.com/settings/usage`; first-connection modal title "You're using your ChatGPT plan", button "Got it".
- Visual rules from UI.md: hairline edges (`.edge`), no drop shadows, no pulsing rings or radar; motion tokens from `lib/motion.ts`; keyboard-triggered actions never animate; `prefers-reduced-motion` honoured.
- App name "Grid"; npm package `gridbots`; licence MIT.

## Review Focus

1. **No usable model** (nothing connected, bad key, provider down, local server stopped): the bot shows the `stuck` pose and an inline error with one action ("Connect a model", "Check key", "Retry"); no blank or endless stream. Tested in Task 8 (`chat route returns a typed error when the model fails`) and Task 9 e2e.
2. **ChatGPT plan cap or expiry**: 429 `subscription_sharing_usage_limit_exceeded` shows "You've hit your ChatGPT plan limit" + "Manage usage"; an expired access token refreshes silently; a dead refresh token shows "Reconnect ChatGPT". Tested in Task 5 (`mapChatgptError`, `getAccessToken refreshes when expiring`).
3. **Local model without tool support** (many Ollama models): chat still works with tools switched off. Tested in Task 4 (`ollama model without tools capability reports tools:false`) and Task 8 (`omits tools when model has no tool support`).
4. **A web page in the same browser attacking the local API** (CSRF / DNS rebinding): requests without `x-grid: 1`, with a foreign `Origin`, or with a `Host` other than `127.0.0.1:<port>`/`localhost:<port>` get 403. Tested in Task 3.
5. **Closing the tab mid-reply**: the assistant message is still saved complete. Tested in Task 8 (`saves the reply even if the client disconnects`).
